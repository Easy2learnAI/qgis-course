# مجلد المواد

هذا المجلد فارغ حالياً. عندما تجهز ملفات التمارين (PDF أو بيانات مضغوطة):

1. ضع الملف هنا.
2. أضفه إلى قائمة `materials` للوحدة المناسبة في `assets/js/data.js`، مثلاً:
   `materials: [{ label: "كتاب التمرين 1", file: "materials/ex1.pdf", type: "pdf" }]`
3. يظهر قسم «المواد» في صفحة الوحدة تلقائياً.
