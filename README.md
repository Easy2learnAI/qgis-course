# موقع Delta Conception — التشغيل المحلي

موقع ثابت (HTML / CSS / JavaScript) بدون قاعدة بيانات وبدون أي تثبيت إضافي.

## 1. التشغيل على جهازك (localhost)

**الطريقة الأسهل — Windows:** انقر مرتين على `start-windows.bat`.
يفتح المتصفح على `http://localhost:8000`. اترك النافذة السوداء مفتوحة؛ أغلقها لإيقاف الموقع.

**macOS / Linux:** في الطرفية داخل المجلد: `./start-mac-linux.sh`

**بدون Python:** افتح `index.html` مباشرة بالنقر المزدوج — كل الصفحات تعمل.
أو في VS Code: ثبّت إضافة **Live Server** ثم زر الفأرة الأيمن على `index.html` ← *Open with Live Server*.

> الخطوط العربية وخريطة مناطق الدراسة تُحمَّل من الإنترنت. بدون اتصال يعمل الموقع بخط احتياطي ورسالة بدل الخريطة.

## 2. الصفحات

| الصفحة | المحتوى |
|---|---|
| `index.html` | الرئيسية: خريطة تفاعلية (إسناد جغرافي + طبقات)، الدورات، أحدث الكتب، الأهداف، مسار الوحدات، مناطق الدراسة، الأسئلة الشائعة |
| `courses.html` | كتالوج كل الدورات مع التصفية حسب المجال |
| `books.html` | مكتبة الكتب: يراها الجميع، والتحميل للمتدرّبين المفعَّلين فقط |
| `program.html` | جدول برنامج دورة QGIS |
| `lesson.html?u=0` … `?u=6` | صفحة لكل وحدة: الأهداف، محتوى التمرين، السابق/التالي |
| `resources.html` | روابط البرامج، معجم مصطلحات عربي/فرنسي/إنجليزي مع بحث |
| `register.html` | نموذج التسجيل مع اختيار الدورة والتحقق من الحقول |
| `files.html` | الدخول، الملفات المحمية، تغيير كلمة المرور |
| `admin.html` | لوحة الإدارة (بالعربية): المتدرّبون، الملفات، محتوى الدروس، الكتب |

كل الصفحات بثلاث لغات (العربية، English، Français) من أزرار اللغة في الرأس، ما عدا لوحة الإدارة.

## 3. التعديل

- **اسم الموقع، البريد، رابط النموذج:** `assets/js/config.js`
- **محتوى الوحدات، الأسئلة، المعجم:** `assets/js/data.js` — كل الصفحات تُبنى منه، عدّل مرة واحدة.
  النص العربي في الحقول بلا لاحقة، والترجمة في الحقول `_en` و `_fr`.
  **مهم:** ترتيب بنود `steps` وعددها في كل وحدة يطابق مفاتيح `guide.json` (1، 2، 3…): لا تحذف بنداً ولا تغيّر ترتيبه إلا مع `guide.json`.
- **الدورات:** دورة QGIS الأولى في `assets/js/courses-data.js`. الدورات الجديدة تُضاف من لوحة الإدارة › «الدورات» › «+ إضافة دورة جديدة» (شغّل `_setup/supabase/courses.sql` مرة واحدة).
- **نصوص الواجهة بالثلاث لغات:** `assets/js/i18n.js` (النص العربي المرجعي يبقى في ملفات HTML نفسها).
- **الكتب:** لوحة الإدارة › «مكتبة الكتب» › «+ إضافة كتاب»: رابط Google Drive + صورة غلاف (رفع من الجهاز أو رابط)، مع تعديل وإخفاء وحذف (شغّل `_setup/supabase/books.sql` مرة واحدة).
- **الدليل المفصّل (طريقة التنفيذ تحت كل بند، Google Earth، النتيجة، الملحقات):** للمتدرّبين المسجَّلين فقط. يُحفظ في الملف `guide.json` داخل المخزن المحمي في Supabase (`course-files/site/guide.json`) ولا يوضع أبداً في ملفات الموقع العامة. لتحديثه: لوحة الإدارة › «محتوى الدروس» › ارفع `guide.json`. الزائر غير المسجَّل يرى عناوين الوحدات والأهداف وبنود التمرين فقط.
- **الألوان والخطوط:** أعلى ملف `assets/css/main.css`
- **ملفات التمارين (لاحقاً):** ضع الملف في مجلد `materials/` ثم أضفه في قائمة `materials` للوحدة في `assets/js/data.js`. يظهر قسم «المواد» في صفحة الوحدة تلقائياً.

## 4. طلبات التسجيل

- **محلياً:** تُحفظ الطلبات في المتصفح. بعد أول تسجيل يظهر أسفل النموذج زر **تنزيل الطلبات CSV** (يفتح في Excel).
- **بعد النشر:** الطلبات تذهب إلى جدول Google Sheets خاص بك، مع رسالة إلى بريدك عن كل تسجيل. خطوات الإعداد (10 دقائق) في `_setup/README.md`.

## 5. النشر لاحقاً (مجاناً)

المجلد جاهز كما هو. ارفع محتواه إلى **GitHub Pages** أو **Netlify** أو **Cloudflare Pages** — لا يحتاج أي تعديل.

## ملفات الدورة المحمية

الدليل ومواد التمارين للمتدرّبين المسجَّلين فقط: صفحة `files.html` (الدخول والتحميل) و `admin.html` (إدارة الحسابات والملفات). خطوات التفعيل في `_setup/supabase/README.md`.
